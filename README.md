**Currently thinking about**

- Most agent deployments automate dysfunction at machine speed. The
  security problem is organizational, not cryptographic.
- The boundary between "information the system can surface" and "this
  requires a human before action" is the most important design decision
  in any AI rollout. Almost nobody draws it explicitly.
- Senior security and infra leaders cap their own leverage by being
  too reliable. The next level is designing systems instead of stepping
  in — and it feels worse before it feels better.
- The real bottleneck for AI-augmented engineering isn't GPUs, it's CI.
- Compliance evidence wants to be automated. Auditors want to trust
  the automation. Those two sentences are a full product roadmap.
